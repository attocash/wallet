Dictionary data: original sources

The data has separate source terms; the software notice above does not
relicense the underlying datasets. The wallet retains the frozen word order
and values from the reference distribution, @zxcvbn-ts/language-common 4.1.3
and @zxcvbn-ts/language-en 4.1.1. Kotlin packaging changes representation only.
The original material and inherited processing are identified below.

DicewareWords.kt / diceware-common (7,776 words):
Electronic Frontier Foundation, Large Wordlist for Passphrases (2016).
https://www.eff.org/deeplinks/2016/07/new-wordlists-random-passphrases
https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt
The frozen list matches Douglas Muth's EFF-derived variant:
https://github.com/dmuth/diceware/blob/main/assets/wordlist/wordlist-5-dice-eff.js
Its four inherited substitutions are drop-down -> dropdown, felt-tip -> felttip,
t-shirt -> tshirt, and yo-yo -> cheetah. All other entries and positions match
the EFF list. EFF's original-material policy identifies CC BY 4.0:
https://www.eff.org/copyright
https://creativecommons.org/licenses/by/4.0/

CommonPasswordWords.kt / passwords-common (49,233 entries):
Mark Burnett, Today I Am Releasing Ten Million Passwords (2015).
https://medium.com/xato-security/today-i-am-releasing-ten-million-passwords-b6278bbe7495
The author states that he releases the dataset to the public domain.
The inherited list is a lowercased, frequency-ranked and filtered derivative;
it is not the complete ten-million-record corpus and contains no usernames.

CommonEnglishWords.kt / commonWords-en (55,830 entries):
OpenSubtitles v2024 English token frequencies, distributed by OPUS / Helsinki-NLP,
from community-contributed subtitles on OpenSubtitles.org.
https://www.opensubtitles.org/
https://github.com/Helsinki-NLP/OPUS/tree/main/corpus/OpenSubtitles/v2024
https://object.pouta.csc.fi/OPUS-OpenSubtitles/v2024/freq/en.freq.gz
The frozen list retains upstream normalization, filtering and order.
Corpus citation requested by the provider: Pierre Lison and Jörg Tiedemann
(2016), OpenSubtitles2016: Extracting Large Parallel Corpora from Movie and TV
Subtitles, Proceedings of LREC 2016.
https://home.nr.no/~plison/pdfs/cl/lrec2016.pdf

The inherited language-en notice identifies ODC-BY and is retained here:

This package includes data derived from OpenSubtitles via OPUS in commonWords.json
(https://opus.nlpl.eu/).

Source dataset: OpenSubtitles 2024
Provider: Helsinki-NLP / OPUS

License: ODC-BY (Open Data Commons Attribution License)

Original data is attributed to subtitle contributors and rights holders.
This package contains a processed derivative:
- tokenized text
- frequency aggregation
- normalization and filtering

Any redistribution of this package must retain this notice.

ODC-BY: https://opendatacommons.org/licenses/by/1-0/

FirstNameWords.kt / firstnames-en (4,945 entries):
Grady Ward, Moby Word Lists, female given names (names-f.txt), Project Gutenberg ebook 3201.
https://www.gutenberg.org/ebooks/3201
https://www.gutenberg.org/files/3201/files/names-f.txt
The Moby documentation contains the author's public-domain release.
https://www.gutenberg.org/files/3201/3201-0.txt
Obtained through Dominic Tarr's random-name list, distributed under MIT:
https://github.com/dominictarr/random-name
The frozen words exactly match lowercasing and first-occurrence deduplication
of the original Moby list; the repeated Gale entry is omitted.

LastNameWords.kt / lastnames-en (88,799 entries):
U.S. Census Bureau, 1990 Census surname-frequency list, dist.all.last.
https://www2.census.gov/topics/genealogy/1990surnames/dist.all.last
https://www2.census.gov/topics/genealogy/1990surnames/nam_meth.txt
Obtained through ARIN Engineering's arincli last-names list:
https://github.com/arineng/arincli/blob/master/lib/last-names.txt
Every frozen entry exactly matches the lowercased Census name column in its
original frequency order. Counts, percentages and numeric ranks are omitted.

WikipediaWords.kt / wikipedia-en (29,782 entries):
English Wikipedia contributors, through the English word-frequency list
published by Dan Wheeler / Dropbox in the original zxcvbn project.
https://en.wikipedia.org/
https://github.com/dropbox/zxcvbn/blob/0e8c7ebc5dd1cda4cbfdaaa37ae445e016f46b2b/data/english_wikipedia.txt
https://github.com/dropbox/zxcvbn/blob/master/data-scripts/count_wikipedia.py
The frozen list retains the inherited ranking and subsequent dictionary
deduplication. The available history does not establish an exact dump date.
Source-text copyright information:
https://en.wikipedia.org/wiki/Wikipedia:Copyrights

WordSequenceWords.kt (14 small lists):
Curated sequence lists authored in zxcvbn-ts: cardinal/ordinal numbers,
weekdays, months, seasons, time periods, rainbow colors, directions,
intermediate directions, sizes, military alphabet, planets, and zodiac signs.
No separate external dataset source is identified. The upstream MIT attribution
above is retained for these lists.

The application terms atto, wallet, attocash, attowallet and atto wallet are
supplied separately as estimator context.
